## 🎯 Overview

This project demonstrates a **production-ready DevOps pipeline** with complete Infrastructure as Code (IaC), CI/CD automation, containerization, and monitoring. The entire infrastructure is deployed to AWS using Terraform with **zero manual steps** - everything is automated!

### ✨ Key Achievements

| Category | Achievement | Status |
|----------|-------------|--------|
| **Infrastructure as Code** | Modular Terraform (VPC, ALB, ASG, EC2) | ✅ |
| **CI/CD Pipeline** | GitHub Actions with DevSecOps (Trivy) | ✅ |
| **Containerization** | Multi-stage Docker, non-root user | ✅ |
| **Auto Scaling** | Dynamic scaling based on CPU | ✅ |
| **Load Balancing** | ALB with health checks | ✅ |
| **High Availability** | Multi-AZ with auto-healing | ✅ |
| **Monitoring** | CloudWatch logs, metrics, dashboards | ✅ |
| **Security** | Vulnerability scanning, private subnets | ✅ |
